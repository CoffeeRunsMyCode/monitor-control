# Contributing

Thanks for taking a look. Bug reports and ideas are welcome. Please [open an issue](https://github.com/coffeerunsmycode/monitor-control/issues) first, especially before a large change, so we can agree on the approach.

**Building:** run `build.ps1`, then `test.ps1` (see the README). No packages or SDK needed.

**A few rules**

- Code must compile with the C# 5 compiler that ships with Windows .NET Framework 4.x.
- Read `docs/ARCHITECTURE.md` before touching display, storage or recovery code.
- Don't include real monitor names, serial numbers or diagnostic files in issues or pull requests. Use `--render-demo` for screenshots.
- Security problems go to [private reporting](SECURITY.md), not public issues.
